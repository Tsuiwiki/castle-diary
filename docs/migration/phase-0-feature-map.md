# 阶段 0 · 功能与数据关系盘点（phase-0-feature-map）

> 依据：PRD V1.0（回归日记本）+ v0.38–0.40 改版已落地的四栏 IA + 用户分期决策。
> 原则：日记是唯一原始载体；分册/记忆视图是查询，不复制数据；健康数据完整保留。

## 1. 原生一期（P0，替代 Capacitor 版日常使用）

| 功能 | 依赖实体 | 备注 |
| --- | --- | --- |
| 当天记录时间线（贴纸条目+文本混排、逐条时间） | 全集合按 date 查询 | 句子生成逻辑参考 diaryText.js buildDayItems |
| 写一页（草稿+显式保存）、一天多篇、编辑/删除 | DiaryEntry | 草稿用内存+DataStore |
| 七种贴纸快速录入（吃了/读了/她说/玩了/去了/不舒服/照片） | TopicItem/ReadRecord/MemoryItem/PlayRecord/MediaAsset/Illness | 录音走 MediaRecord |
| 日期级心情状态卡 | DayState | 旧数据回退已定义 |
| 日历（月视图：条数/心情色/照片底） | monthIndex 口径 | |
| 回忆：她说过的话（非识字、金句筛选）、第一次与重要时刻、相册 | MemoryItem/Moment/MediaAsset | |
| 我的：档案、备份导入导出（v2 格式双向）、应用锁（PIN+生物识别）、设置、成长名片数据 | 全部 | 导入必须两段提交+失败回滚（沿用 store.js 模式） |
| 新手引导 | settings.onboarded | 含"卸载会删数据"提示 |

## 2. 原生二期

书房（书架+阅读记录）、饮食册（彩虹餐盘）、游戏册、足迹册、健康四页（档案/生病记/药箱/提醒）、城堡完整视觉（Compose Canvas：月龄加层/词添砖/里程碑插旗/书点灯/地方种树/四季换装/节气换装）、成长周报、年度回顾、成长书（系统打印 Save as PDF）、月龄卡/名片图片生成。

## 3. 原生三期

识字词库管理+翻卡巩固、玩具屋、提醒中心（本地通知）、今日一问/节气、平板适配、（评估后）OCR。

## 4. 视图与实体的关系（不复制数据）

- 周报/年度/成长书/月龄卡 = 对 DiaryEntry+TopicItem+Moment+MediaAsset 的区间聚合（PWA 端 rangeReport/buildDayItems 为逻辑参考）。
- 记忆收藏室 = 各集合的专题查询。
- 城堡 = 纯派生视觉（层数=月龄，砖=词数，旗=里程碑，灯=读完的书，树=去过的地）。

## 5. 明确不迁移/不开发

社交/云同步/打卡/AI 生成故事（PRD 第九章）；OCR 原生版首期不做（保持全离线）。

# 城堡日记（castle-diary）

一天一页的宝宝成长日记。纯前端、无后端、无账号，数据 100% 存在使用者的浏览器里。

线上地址：<https://tsuiwiki.github.io/castle-diary/>

## 这是什么

给 1 岁以后宝宝的家庭记录工具：**先写日记，再翻分册**。一天一页，用「吃了 / 读了 / 她说 / 玩了 / 去了 / 不舒服 / 照片」几张贴纸把当天的事记下来，自动拼成一段日记；背后按绘本、识字、游戏、饮食、足迹、相册、健康等"分册"保存和统计。

- 日记页：心情 + 贴纸 + 自动造句 + 想说的话 + 落款；会长大的城堡、月龄卡、大盖章
- 分册：书房（OCR 认封面）、识字词库与翻卡巩固（可录她的声音）、饮食册（彩虹餐盘）、游戏册、玩具屋、足迹册
- 回忆：相册、成长周报（可生成分享长图，带隐私开关）、年度回顾、小主人档案
- 健康：健康档案与生长曲线、疫苗接种记录（2026 年版国家免疫规划，标注文号与来源）、生病记、药箱、提醒中心
- 二十四节气：日记抬头节气标签、应景灵感、足迹节气章、城堡随季节换装

## 数据在哪里

- 结构化数据：浏览器 `localStorage`（键 `castle-books-local-v1`）
- 照片 / 录音：浏览器 `IndexedDB`（库 `castle-books`）
- **清理浏览器数据 = 丢数据**。请在应用内「设置 → 备份与迁移」导出备份；电脑版 Chrome / Edge 可开启"自动备份到本地文件夹"
- 没有服务器，没有任何数据离开本机（唯一例外：书封 OCR 识别会把封面图发给 OCR.space，可在设置页关闭不用）

## 本地开发

```bash
npm install
npm run dev    # 开发
npm run build  # 构建到 dist/（相对路径，可在任意子路径部署）
npm run preview
```

技术栈：Vue 3 + Vite 6 + vite-plugin-pwa（全站离线）。无路由库、无状态库，单一响应式 store（`src/store.js`）。

## 发布

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy.yml`）自动构建并发布到 `gh-pages` 分支，即 GitHub Pages 内容。
